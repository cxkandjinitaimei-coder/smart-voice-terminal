# 远程连接测试台（WEB → ESP → F407）

## 链路

1. 网页「远程连接测试」→ `POST /api/command` 入队  
2. ESP 周期/`@ACK` 触发 `POST /api/data`（带 `device_id=esp-bridge`）  
3. 云端响应捎带一条 `command`（无论是否调 AI）  
4. ESP 把网页 `raw` 的 `@...#` 转成 `@...\n` 发给 F407；或拆 `moves`/`text`  
5. F407 执行舵机并回 `@ACK:...` → ESP 立刻上报 → 网页显示最近 ACK  

异常仍走原面板：`need_ai=true` → AI 信封 `moves[]` → ESP 拆帧。

## 服务器 IP（UDP 自动发现 · ★ 2026-09-20 新增）

**不用再手改 IP，也不用为换网重烧 ESP。** ESP 上电（以及服务器不可达时）主动广播问路，
`app.py` 直接把自己的当前 IP 报回来。

```
ESP  ──UDP 广播 255.255.255.255:5001  +  子网广播:5001──►  ARDP_DISCOVER
ESP  ◄─────────────UDP 单播──────────────  PC:5001  ARDP_IP:10.x.x.x:5000
```

| 端 | 在哪 | 常量 |
|---|---|---|
| ESP | `sketch_aug28a.ino::discoverServer()`（B-10） | `DISCOVER_PORT=5001` / `DISCOVER_MAGIC` |
| PC | `flask_relay/app.py::beacon_loop()`（C-14） | `BEACON_PORT=5001` / `BEACON_MAGIC` |

- ⚠️ **端口和口令两端必须一致** —— 不一致**两边都收不到、而且不报错**（这是本机制唯一的静默风险）。
- ★ PC 回的是**面对 ESP 那张网卡的 IP**（用 `connect(对端IP)` 让内核选路），不是随便一张网卡的 ——
  本机有 VMware 的 `192.168.255.1` / `192.168.30.1`，报错了 ESP 就连不上。
- ★ **要 `app.py` 正在跑才有人应答**。没人应答不算错：ESP 会退到 `sketch_aug28a.ino::SERVER_IPS[]` 兜底，
  并每 5 秒重问一次。连不上时它还会**作废已发现的地址**再重问 ⇒ PC 换 IP / 关机再开都能自愈。
- **判据**：Flask 启动日志有 `[BEACON] 服务器 IP 自动发现已就绪（UDP 5001…）`；
  ESP 来问路时打 `[BEACON] <ESP_IP> 来问路 → 告诉他 <本机IP>:5000`。
  ESP 侧（`Serial1` → D4，需第二个 USB-TTL）有 `[DISC] 问到服务器: <IP>`。
- ⚠️ **看不到 `已就绪` 那行** ⇒ UDP 5001 没绑上，最常见的原因是**已经有一个 app.py 在跑**
  （Windows 上 `SO_REUSEADDR` 允许重复 bind，但收包只给后绑的那个 ⇒ 问路时灵时不灵）。
- 老办法仍然有效（应急）：`ipconfig` 看当前 WLAN 网卡 IP → 改 `SERVER_IPS[0]` → 重烧 ESP。
  ⚠️ 别抄旧记录里的 IP（本项目已换过 5 次：`10.198.225.10` → `192.168.3.140` → `10.105.189.10` → `10.247.58.10` → `10.217.194.10`）。

## 网页帧格式

- 开始：`@`，结束：`#`
- 例：`@MOVE:servo,1,100#`、`@SWEEP:servo,1#`、`@LED_ON,LED1#`、`@MOVE:servo,2,45#@LED_OFF,LED2#`
- ESP 翻译：`@MOVE:servo,1,100\n`（F407 仍按行解析）
- 快捷键可在网页自由添加/删除，保存在浏览器 localStorage（当前存舵机+LED 默认键）

## F407 白名单命令

| 帧（网页 `#` 写法） | F407 收到的行 | 效果 | ACK |
|---|---|---|---|
| `@MOVE:servo,1,100#` | `@MOVE:servo,1,100` | 舵机1→100°（测试期放开 0~180） | `@ACK:ok,servo,1,100` |
| `@MOVE:servo,2,45#` | 同上 | 舵机2→45°（0~180） | `@ACK:ok,servo,2,45` |
| `@MOVE:servo,3,45#` | 同上 | 舵机3→45°（0~180） | `@ACK:ok,servo,3,45` |
| `@SWEEP:servo,1#` | `@SWEEP:servo,1` | 舵机1 连续扫动 0↔180（F407 本地动画） | `@ACK:ok,servo,1,sweep` |
| `@SWEEP:servo,2#` | 同上 | 舵机2 连续扫动 | `@ACK:ok,servo,2,sweep` |
| `@SWEEP:servo,3#` | 同上 | 舵机3 连续扫动 | `@ACK:ok,servo,3,sweep` |
| `@LED_ON,LED1#` | `@LED_ON,LED1` | PA6 亮（低电平点亮） | `@ACK:ok,led,LED1,on` |
| `@LED_OFF,LED1#` | `@LED_OFF,LED1` | PA6 灭 | `@ACK:ok,led,LED1,off` |
| `@LED_ON,LED2#` | `@LED_ON,LED2` | PA7 亮 | `@ACK:ok,led,LED2,on` |
| `@LED_OFF,LED2#` | `@LED_OFF,LED2` | PA7 灭 | `@ACK:ok,led,LED2,off` |

- **LED1=PA6，LED2=PA7**，低电平点亮（走 `LED_PWM_SetBrightness()`，TIM3_CH1/CH2，`level` 0~999）。
- ★ **`@SWEEP:servo,<id>` 是「有限扫」（2026-09-18 起）**：**8 步 × 800ms ≈ 6.4 秒后自己停**，不是无穷扫 —— 无人值守的无穷扫会烤舵机、磨齿轮，看着还像板子失控。它走的是和手势共用的**非阻塞步进器**（不能用 `delay`，否则饿死麦克风的 64ms 环形缓冲和按键扫描）。
- ★ **id 口径（2026-09-18 定案）= 模块丝印号 1~16 直通**（`PCA_ID_TO_CH(id) = id - 1`，宏在 `pca9685.h`）⇒ **丝印 1 = 协议 id 1**。⚠️ 硬件要跟着动：**丝印 2/4/6 的线挪到 1/2/3**（不挪的后果是"**舵机动了、但不是你以为的那一个**"）。
- ★ **"测试期放开 id1 全行程"现在在云端/Python 侧做**（改 `config.json::hardware.servos` 的角度上下限）。**固件里没有 `SERVO_TEST_RELEASE_S1` 这个宏** —— 别再去 `main.c` 找它，也别找 `servo_sweep_update`（已不存在）。
- ★ **本轮固件不回 `@ACK`**：下表的 ACK 列是**协议设计意图**。`App/ailink.c` 目前**只执行、不回执** ⇒ 网页"最近 ACK"不会刷新，别拿它当执行判据；判据是**舵机动没动 / 屏上变没变**。
- ★ **白名单口径（2026-09-18 用户定案）**：F407 **两套帧都认**（AI 决策帧 + 网页遥控帧）⇒ **网页 `filterAllowedFrames()` 是固件白名单的「子集」**，当"防误点"的第二道闸，**不再要求两边逐条一致**。固件那份见 `App/ailink.c`（`项目地图.md` 卡片 **A-29**）。
- ⚠️ **未知帧在固件侧一律丢弃**，**绝不能转发给 `Media_Command`** —— 它的兜底会把任何非 `/` 开头的行**当文字直接上屏、且不报错**（屏上出现 `@MOVE:servo,1,90` 原文就是这么来的）。

## 接线（NodeMCU 硬件串口，不要用 SoftSerial D1/D2）

```
ESP GPIO1 (TX)  →  F407 PC7 (USART6 RX, H1（右侧）第 38 针)
ESP GPIO3 (RX)  ←  F407 PC6 (USART6 TX, H1（右侧）第 39 针)
GND ↔ GND（H1（右侧）第 7~10 针）
波特率 115200（★ 两端都要改：esp_uart.h::ESP_BAUD + sketch_aug28a.ino::F407_BAUD）
ESP 的 3V3 必须独立供电（峰值 300mA+），别从 MCU 的 LDO 取
```

F407 串口层：`ST32/AIAssistant/Hardware/14ESP_UART/esp_uart.c`（**USART6/PC6-PC7@115200**）  
F407 帧解析 + 白名单：`ST32/AIAssistant/App/ailink.c`（**A-29**）  
ESP 侧用硬件 `Serial`（GPIO1/3），调试日志走 `Serial1`（GPIO2/D4，可选）。

舵机：**协议 id = 丝印号直通**。id1 点头（测试放开 0~180）；id2 左右 0~180；id3 预留 0~180；中值 90。
⚠️ **线要插在丝印 1/2/3 上**（不是 2/4/6）。
