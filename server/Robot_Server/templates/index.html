真机时序：F407 检测到异常 → 发 @ALERT:描述 给 ESP → ESP 用下面同样的 body {"user":"…","need_ai":true} 上报云端 → 云端返回决策（信封 JSON）→ ESP 逐条 moves[] 拆成类型化帧发给 F407。 这里没有硬件也能验证整条链——结果里同时展示「决策信封」和「ESP 将转发给 F407 的类型化帧」。
