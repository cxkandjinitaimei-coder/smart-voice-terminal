# MAX98357 / MAX9835 数字功放使用说明

本目录提供 F407 的 I2S 数字功放播放驱动。它面向 MAX98357、MAX9835 这一类带 I2S 输入的模块，播放链路为：

`AI 回复文字 → 云端 TTS WAV → ESP8266 → F407 UART 二进制帧 → I2S2 → 功放 → 喇叭`

## 接线

| 功放模块 | STM32F407 | 说明 |
|---|---|---|
| DIN / SD | PB15 | I2S2_SD，AF5 |
| BCLK / BCLK | PB10 | I2S2_CK，AF5 |
| LRC / WS | PB9 | I2S2_WS，AF5 |
| GND | F407 GND | 必须共地 |
| VIN | 按模块丝印供电 | 常见模块支持 5V，但以实物标注为准 |
| SPK+ / SPK- | 喇叭两端 | 桥接输出，不能接地 |

GAIN、SD/EN 等脚按模块的丝印和数据手册处理。没有确认模块后缀前，不要默认把 SD/EN 悬空或直接接 3.3V。

## 音频格式

当前驱动只接受标准 PCM WAV：

- 采样率：16 kHz
- 位深：16 bit
- 声道：单声道
- 字节序：小端
- 不接受 MP3、AAC 或双声道 WAV

ESP8266 只跳过 WAV 头并转发 PCM，不在板上解码 MP3。云端 TTS 返回的 WAV 不符合上述格式时，播放会被拒绝，文字和动作仍可继续。

## 播放与录音互斥

录音和播放共用 I2S2 的时钟资源。F407 收到播放 BEGIN 后暂停 INMP441，播放结束后重新初始化并启动麦克风；不要在播放期间强行启动录音。播放 DMA 使用 DMA1 Stream4，麦克风接收仍使用原来的 DMA1 Stream3。

## 协议概要

ESP 到 F407 的帧格式：

`A5 5A | type | seq(低字节,高字节) | len(低字节,高字节) | payload | XOR`

| type | 含义 |
|---:|---|
| `0x05` | BEGIN：16000、16 bit、mono |
| `0x06` | PCM：小端 PCM 分片 |
| `0x07` | END：本段结束 |
| `0x08` | F407 ACK：状态 0 接收、1 缓冲满、2 错误 |

## 安全要求

1. **全部断电后再接线，禁止热插拔。** 用户此前出现过 ESP8266 热插拔导致 F407 发热/损坏的情况。
2. F407、ESP8266、功放模块必须共地；功放可以独立供电，但地线要可靠相连。
3. `SPK+` 和 `SPK-` 是桥接输出，喇叭任何一端都不能接 GND，也不能与其他功放输出并接。
4. 先不接喇叭时可以测量 VIN/GND 电压；确认电压和极性后再接喇叭。
5. 建议使用 4 Ω 或 8 Ω、功率不超过模块额定值的喇叭，并给功放电源留出峰值电流余量。
