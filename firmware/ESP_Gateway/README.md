# ESP_Gateway

首次安装Arduino开发环境、Core和库，请先读[ESP8266环境搭建](../../docs/ESP8266环境搭建.md)；完整系统按[环境搭建与依赖说明](../../docs/环境搭建与依赖说明.md)执行。

本文说明本目录网关工程的配置、编译、接线和调用关系。首次使用先阅读“打开和配置”，理解代码时先看各文件头的职责/使用方法，再沿主循环进入对应模块。

NodeMCU ESP8266 网关，公开源码审阅版 **1.0.0**。负责 F407 与中转服务之间的数据传输；AI 对话和语音识别由服务端处理。本目录不含 Wi-Fi 密码、真实服务器地址、访问口令或预编译固件。

## 打开和配置

1. 将 `gateway_config.example.h` 复制为 `gateway_config.h`，填写 Wi-Fi、服务器地址、端口和 token。token 必须与中转服务一致。
2. Arduino IDE 打开 `ESP_Gateway.ino`，开发板选 **NodeMCU 1.0 (ESP-12E Module)**。
3. 安装 ESP8266 Arduino Core **3.1.2** 和 ArduinoJson **7.4.3**。代码保留兼容旧 JSON API，编译时可能出现弃用提示；本轮未迁移 JSON 库接口。其他 Wi-Fi、LittleFS、HTTP、OTA 库来自板卡包。
4. Flash 选 **4MB (FS:2MB OTA:~1019KB)**；音频和图片均使用 LittleFS，运行文件系统至少需同时容纳缓存和已有配置。接入的 F407 必须使用匹配的帧协议和扩容布局。

命令行编译（需先安装上述板卡和库，且完成本地配置）：

```powershell
arduino-cli compile --fqbn "esp8266:esp8266:nodemcuv2:eesz=4M2M" --warnings default .
```

此命令在当前工程目录运行。可以任意移动或重命名外层项目目录，源码不包含开发电脑的绝对路径。Arduino 要求内部目录 `ESP_Gateway` 与主文件 `ESP_Gateway.ino` 同名；如需改内部工程名，两处一起改。设备 ID 是服务器队列标识，独立于文件夹名和未来产品/AI 名称。

## 接线

| NodeMCU | F407 / 用途 |
| --- | --- |
| GPIO1 / TX | PC7 / USART6 RX |
| GPIO3 / RX | PC6 / USART6 TX |
| GND | 共地 |
| GPIO2 / D4 | 可选 USB-TTL RX，仅输出调试日志 |

板间 UART 为 **921600 baud、8N1、3.3V 电平**；D4 日志为 **115200 baud**。上传 ESP 固件时按实际电路隔离与 USB 串口的冲突。UART0 只发送协议，不能插入普通调试日志。

## 数据与调度

传感器/姿态由 F407 通过 UART 上报，ESP 在空闲时 `POST /api/data`，从响应取得网页指令、AI 动作、参数修订和 OTA 公告。局域网优先 UDP 自动发现，配置的服务器地址作为兜底。稳定设备 ID 和发现报文保持兼容，不跟随工程名称改变。

主循环先接收串口、推进音频，再推进拍照和 OTA，最后运行普通轮询。`busy` 标志表示任务占用，采用主循环协作协调，没有 FreeRTOS 互斥锁。网络连接和部分 OTA 步骤仍有有界阻塞，本轮没有声称实现全非阻塞或改善网络性能。

音频经 RAM 暂存后分批写 LittleFS，同时尽量上传；网络落后时保留 Flash 完整副本，结束后补传。只有服务器确认实际字节数完整才删除缓存并通知 F407 READY。VAD 的触发、断句及音频采样在 F407 上完成，ESP 接收可变长度录音并用 HTTP chunked 上传。

拍照一次接收 **320×240 RGB565，153600B**，每块512B并核对块/整帧CRC；先落盘，再上传并等待服务端确认。没有视频流，也没有在 ESP 上做人脸识别。

F407 OTA 先经实体按键确认，再下载/擦写。云端4096B块先完整校验，再拆128B发送；最后按 END → COMMIT → JUMP 执行，复位后主动发 INFO，比较填充后的 Slot A CRC 才完成复核。匹配布局为 A=`0x08008000`、224KiB，layout=`0x00020001`；同一源码树中的 F407 和 Bootloader 沿用这个布局。

## 版本与验证边界

此副本从开发版 ESP **1.1.13** 整理为公开首版 **1.0.0**。原有三段版本比较规则未改：旧1.1.13不会通过自动检查接受1.0.0。如果将1.0.0写入设备，而服务器仍发布旧1.1.13，它会将旧开发版视为更高版本。若决定实际迁移，需一并安排首次写入和服务器固件版本，不能把本目录当作现有设备的直接自动升级包。

本目录是完整 1.0.0 源码中的 ESP8266 网关部分，F407/Bootloader、上位机及工具位于同一项目的其他目录。整理包含详细注释、配置抽取和统一格式；旧开发工程和历史交付均保留，没有刷板、提交 Git 或发布 GitHub。验证记录见 [验证说明](../../docs/validation.md)；编译和主机协议回归不能代替实板的网络/音频/摄像头长期测试。

本目录只包含项目网关代码；Arduino Core、ArduinoJson 等第三方依赖仍遵循各自许可证，本轮未改写第三方版权或代其授权。

## 注释约定

每个代码文件开头说明职责、使用步骤、调用关系、数据格式及边界；主要接口说明输入、返回值与调用时机。函数内部解释缓冲归属、校验顺序、ACK含义、背压、超时、状态迁移和释放路径。简单赋值不逐行复述，注释中的成功会区分接收、落盘、上传确认和识别完成。
