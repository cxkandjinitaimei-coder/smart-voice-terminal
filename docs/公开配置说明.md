# 公开配置说明

仓库中的配置文件只提供模板。每台设备第一次运行时，在本地复制模板并填写自己的值；不要把填写后的文件提交到 Git。

## ESP8266

```powershell
Copy-Item firmware/ESP_Gateway/gateway_config.example.h firmware/ESP_Gateway/gateway_config.h
```

填写 Wi-Fi 名称、密码、Flask 服务地址和 API token。服务端 token 必须与 `config.json` 相同。`gateway_config.h` 已被 `.gitignore` 排除。

## Flask 服务

```powershell
Copy-Item server/Robot_Server/config.example.json server/Robot_Server/config.json
```

把 `token` 改为随机长字符串，在 `providers` 中填写自己的 API 地址、模型和 Key。没有 AI Key 时可以使用网页测试和模拟决策。
服务首次启动还会在服务目录生成 `.session_key`，它只用于网页登录 session 签名，也不要提交。

## ESP32-S3 相机

相机工程的 `network_config.h` 只保留空模板。推荐通过配置页写入 Wi-Fi；如果在代码中配置，使用本机未跟踪的覆盖文件，不能提交密码或 token。

## 发布前检查

提交前执行：

```powershell
rg -n --hidden 'YOUR_|<SERVER_|password|token' .
```

确认真实密码、API Key、公网地址、数据库、录音、照片、人脸库、模型和编译输出均未进入暂存区。
