# 已知限制

- **裸机协作调度**：前台任务共享执行时间；USART发送、DHT11、SD和Flash等路径仍存在阻塞。不能把 Tick 接口理解成所有调用都完全非阻塞。
- **RAM紧张**：F407实际链接占用见验证记录，尚未新增RTOS线程栈或完整双声道缓冲。扩展功能需重新核算 SRAM/CCM 和 DMA 可访问范围。
- **语音尾延迟**：ESP缓冲/发送可与录制重叠，但 ASR 等完整句子，且模型/AI耗时受CPU、网络及任务队列影响；不保证公网停止说话后一秒内回复。
- **相机吞吐**：320×240 RGB565一帧153600B；921600/8N1理论有效字节率92160B/s，仅串口搬运至少约1.67秒，另有协议、FIFO、Wi-Fi与推理时间。当前不是视频流。
- **飞线稳定性**：原摄像头曾随线束/摆放姿态出现错色横条，接触、信号完整性与电源仍需实板验证。本次代码整理不宣称修复硬件。
- **识别边界**：YuNet/SFace受人脸像素、角度、模糊、朝向和光照影响；坐标/角度计算依赖相机视场角标定。当前不自动闭环跟踪舵机。
- **姿态反馈**：是板端插值估计，没有编码器，不等于机械实测位置。
- **双麦/扬声器**：完整双声道与语音播放未在当前应用启用；独立看门狗驱动也未纳入本版工程，不宣称已开启。
- **OTA安全与掉电**：CRC用于完整性，不是签名；下载槽不是第二个可直接运行的回滚槽。安装覆盖A期间的掉电保护有边界，见Flash文档。
- **模型与资产**：权重、录音、人员照片、完整SD美术不随源码分发。生成字体的来源许可尚需发布者确认；不要扩大MIT范围。
- **运行配置**：服务与ESP必须使用一致的私有token；网页登录口令与设备鉴权沿现有单实例设计，尚未引入多租户账号体系。默认Flask启动器用于联调。
- **版本迁移**：公开1.0.0不能直接通过现有ESP规则从1.1.13自动降级；需同步迁移计划。

这些是当前功能的实际边界，不是新增故障列表。本次未刷硬件、未部署局域网/公网服务，也未验证长期运行和电源噪声。
