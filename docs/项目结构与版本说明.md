# 项目结构与版本说明

公开版本使用职责命名，顶层产品名仍可在后续确定；修改目录名不会改变固件内部协议。

- `firmware/STM32_Controller`：F407 应用与 Bootloader，应用从 Slot A 链接。
- `firmware/ESP_Gateway`：ESP8266 网关，`ESP_Gateway.ino` 是 Arduino 入口。
- `firmware/ESP32S3_Camera`：独立相机网络服务。
- `server/Robot_Server`：网页和服务端模块，`app.py` 为入口。
- `tools`、`docs`、`tests`：可复用工具、设计文档和回归验证。

版本号 `1.0.0` 表示公开源码快照，不代表设备当前运行的开发固件版本。正式交付时另行生成日期目录和校验清单，历史交付包不覆盖。
