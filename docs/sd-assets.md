# SD 表情素材

代码不附带个人/AI 生成的完整美术资源。使用自己拥有使用权的图片，按驱动格式生成 SD 文件；缺图时程序提供回退或错误提示，编译成功不代表已准备好 SD 素材。

## 默认静态图

GUI 默认头部可放 `FACE/GUINORM.BMP`，倾听图可放 `FACE/GUILIST.BMP`；160×160、24位无压缩BMP。兼容表情也可使用 `FACE/HAPPY.BMP` 等大写短文件名。不要使用不受当前 FatFs 配置支持的中文长文件名。

## 动画

动画目录为 `FACE/<片名>/0000.R16`、`0001.R16`……，从0开始、顺序不变。缺少快速格式时播放器尝试同名24位BMP。

| 片名 | 帧数 | 片名 | 帧数 |
| --- | --- | --- | --- |
| BLINK | 45 | SHY | 60 |
| HAPPY | 42 | GLASSES | 57 |
| ANGRY | 42 | FUNNY | 51 |
| WINK | 48 | POUT | 48 |
| LAUGH | 66 | STARRY | 39 |
| RIGHT | 54 | SLEEP | 48 |
| DOUBT | 45 | LOOK | 54 |
| SMILE | 36 | SURPRISE | 56 |
| THINK | 40 | | |

片名/帧数来自 `App/face_anim.c::clips`，共831帧。新增片名或改变帧数需更新驱动元数据并重新编译，不能仅多放一张图片。

```powershell
python tools/sd_assets.py <源素材目录> <独立输出目录> --normal <普通表情.png> --listen <倾听表情.png>
```

工具将每个片名目录内文件按自然数字顺序读入，重编号为四位序号，生成 BMP 和 R16。输出检查完成后手动把 `FACE` 目录复制到 SD 根目录。不会自动清卡或覆盖源素材。

## R16 格式与刷新

文件实际扩展名为 `.R16`，不是通用图片格式。前16B是小端 `D565`/宽160/高160/数据长51200，补齐到512B；之后是从上往下的小端RGB565像素，总长51712B。

播放器一次前台切片读取/画8行，随后让出给协议和动作；兼容BMP最多4行或达到软时间预算即返回。一个SD读取可能超过预算，所以不声称硬实时。目标间隔默认40ms、最高可设置25FPS，实际刷新受卡速、调度、忙状态影响。录音/升级时按业务保护暂停动画，以状态条反馈。

字库使用板外W25Q。现有字模数据保留用于兼容；字体许可范围见第三方说明。不要把不明来源字模重新标为项目自有资源。
