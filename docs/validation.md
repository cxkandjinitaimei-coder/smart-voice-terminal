## F407 与 Bootloader

将整理后的源码复制到名称含空格的新根目录，使用 ARMCC 5.06 update 7 build 960、STM32F4xx DFP 3.1.1 完整构建。三个工程均为 **0 Errors、0 Warnings**，相对路径、头文件和 scatter 依赖齐全。

| 工程 | BIN 字节数 | 初始 MSP | Reset 向量 |
| --- | ---: | --- | --- |
| STM32_Controller | 104224 | 0x2001EA60 | 0x080001A1 |
| STM32_Controller_OTA | 104224 | 0x2001EA60 | 0x080081A1 |
| STM32_Bootloader | 16384 | 0x20000C10 | 0x080001C1 |

Bootloader BIN 包含固定位置的布局描述及填充，文件长度不等于有效指令长度。应用链接报告为 Code=90044、RO=14028、RW=1024、ZI=124512 字节；RW+ZI=125536 字节，距离128KiB约剩5.4KiB。这不是可直接分配的堆余量，新增缓冲、线程栈或双声道前仍需核对链接布局、现有栈和DMA访问范围。Bootloader为 Code=6600、RO=1396、RW=16、ZI=3072 字节。

另检查了引导描述、应用入口、HEX 校验和与地址范围；合并 Bootloader/OTA HEX 后的数据等于两个输入的并集，未写入 META 区。没有生成供现有设备直接使用的迁移固件包。

构建中确认两项工具链要求，已保留在源码中：

- 自有中文 C/H 保持 UTF-8 BOM，避免 ARMCC5 误判字符编码；原供应商编码不机械转换。
- `boot_enter` 内联汇编依赖指令换行，用格式化开关保护，不能只用去空白 token 比较验证汇编语义。

**19组回归通过，0组失败**，包含78个 unittest 用例和脚本断言套件。范围包括固定舵机限位/回正、独立速度和AI指令、时间计划、待机动作、鉴权、OTA、音频队列/归档/保留、拍照传输、人脸登记匹配、旋转坐标、配置初始化、版本及便携工具。旧测试中不再符合物理限位的夹具已调整，没有放宽生产代码校验。

复验命令（在根目录，先安装依赖）：

```powershell
python tools/set_version.py --check
python tools/build_stm32.py --keil "<Keil目录>/UV4/UV4.exe" --fromelf "<Keil目录>/ARM/ARMCC/bin/fromelf.exe"
python tools/run_checks.py
```

包含实际人脸模型的扩展检查需自行提供目录：

```powershell
python tools/run_checks.py --face-assets "<测试图片目录>" --face-models "<模型目录>"
```
