# 网页服务环境搭建

适用目录：`server/Robot_Server`。所有命令默认在**项目根目录**执行；路径可有空格，整段路径用引号。Windows以PowerShell为例，Linux命令单独列出。

## 一、准备软件

- 安装64位Python，项目建议3.10+，新环境可先选3.11/3.12。官网下载：<https://www.python.org/downloads/>。
- 准备现代浏览器。代码已包含网页静态文件及Chart.js/Three.js，不需要安装Node.js或运行npm。
- AI联网、模型下载和pip安装需要相应网络；仅局域网访问网页无需公网地址。

Windows先执行`py --version`或`python --version`确认可用。下例使用`python`；若电脑只有`py`，只把创建环境那条命令改为`py -3 -m venv .venv`，后续始终使用虚拟环境解释器。

## 二、Windows安装与启动

先在资源管理器进入项目根目录，在地址栏输入`powershell`打开终端。

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r server/Robot_Server/requirements.txt
.\.venv\Scripts\python.exe -m pip check
```

这里直接调用`.venv`中的Python，不依赖`Activate.ps1`，无需为激活脚本修改PowerShell执行策略。以后安装库、运行服务和工具都使用同一个解释器，避免“明明装了却找不到模块”。

首次生成私有配置：

```powershell
.\.venv\Scripts\python.exe server/Robot_Server/start_server.py --init-config
```

生成`server/Robot_Server/config.json`；已存在时保留原内容。程序从`config.example.json`创建，并随机生成token，终端不打印密钥。用编辑器在本机查看配置即可。

主要字段：

| 字段 | 用法 |
| --- | --- |
| `host` | 局域网设备接入使用`0.0.0.0`，表示监听本机各网络接口；它不是浏览器访问地址 |
| `port` | 默认5000，必须与ESP的`GATEWAY_SERVER_PORT`相同 |
| `token` | 至少16字符的私有口令；用于登录及设备鉴权，复制到ESP的API token配置 |
| `display_name` | 网页/角色名称，不改变内部工程目录和设备ID |
| `persona` | 管理员自定义角色说明；可先留空 |
| `providers` | AI提供商配置；不使用AI时先保留禁用状态 |

启动：

```powershell
.\.venv\Scripts\python.exe server/Robot_Server/start_server.py
```

浏览器打开<http://127.0.0.1:5000/>，用`config.json`的token登录。终端应持续运行，关闭窗口或按Ctrl+C会停止服务。启动器会启动服务、存储/定时任务和UDP发现线程；不要只导入`app`就认定这些后台线程已经运行。

## 三、Python依赖用途与约束

以`server/Robot_Server/requirements.txt`为实际安装清单：

| 包 | 当前约束 | 用途 |
| --- | --- | --- |
| Flask | `>=2.0` | 网页、JSON接口、登录会话、媒体文件访问 |
| requests | `>=2.25` | AI API和其他HTTP请求 |
| Pillow | `>=10.4,<13` | 图片处理、SD素材转换 |
| faster-whisper | `==1.2.1` | CPU语音识别与语音活动过滤 |
| av（PyAV） | `==18.1.0` | 实际音频解码；与上述faster-whisper配对 |
| opencv-python-headless | `==4.14.0.94` | 无桌面依赖的OpenCV，人脸检测/匹配和图像处理 |
| NumPy | `>=2,<3` | 音频/图像数组运算 |
| huggingface-hub | `>=0.24,<2` | 显式下载、定位和复用语音模型缓存 |

pip会安装这些包的间接依赖，例如CTranslate2、ONNX Runtime、tokenizers。无需分别寻找同名文件复制到项目。正常安装预编译PyAV wheel时不要求另装`ffmpeg.exe`；若pip开始从源码构建底层库，应先检查Python版本、系统架构和安装源是否提供对应wheel。

本机既有回归环境实际使用Python3.14.7、Flask3.1.3、requests2.34.2、Pillow12.3.0、faster-whisper1.2.1、av18.1.0、NumPy2.5.2、huggingface-hub1.32.0；cv2由`opencv-python4.14.0.94`提供。公开requirements选用同版本的headless变体，避免Linux依赖桌面显示组件；这不是“已在所有Python版本重新安装成功”的声明。

**不要在同一虚拟环境混装多个OpenCV变体**，它们共享`cv2`模块。已有其他项目环境时，优先创建本项目独立`.venv`，不要为了安装本项目去改坏别的环境。

## 四、AI API配置

服务调用兼容`chat/completions`的接口，使用requests，不要求安装某家提供商SDK。编辑私有`config.json`，例如将`providers.example`修改为：

```json
{
  "enabled": true,
  "base_url": "https://api.example.com/v1",
  "model": "your-model-id",
  "keys": ["REPLACE_WITH_REAL_PRIVATE_KEY"],
  "json_mode": true,
  "temperature": 0.7,
  "max_tokens": 1024
}
```

这是替换该提供商对象的示例，不是覆盖整个config文件。将根字段`active_provider`设为`example`或保持`auto`。`base_url`后由代码追加`/chat/completions`，因此不要填写完整聊天接口，也不要重复追加`/v1`。模型ID与Key以所选服务商为准。

如服务不支持JSON响应模式，可将`json_mode`改为false，但最终回复仍需符合本项目的决策格式。AI调用代码使用直连，不自动采用系统代理；“浏览器能访问、后端请求失败”时要核对服务所在机器的真实出网条件。修改配置后首次搭建建议重启服务再测试。

不配置AI仍可测试网页、设备控制和上传。语音识别能得到文字并不代表已开启自动交AI；还需在网页相应控制项启用该流程，并验证提供商可用。

## 五、同Wi-Fi设备访问

Windows执行：

```powershell
ipconfig
```

查看与ESP同网段的Wi-Fi网卡IPv4，例如`192.168.1.100`。手机/其他电脑访问`http://192.168.1.100:5000/`，ESP候选地址也填该IP。不要填127.0.0.1、0.0.0.0、VPN网卡地址或不相通的虚拟网卡地址。

Windows防火墙需允许该Python程序在所用局域网接收入站TCP5000、UDP5001。可以在首次弹窗中允许专用网络，或在防火墙高级设置创建范围合适的规则，无需关闭整个防火墙。修改HTTP端口后同步更新ESP配置；自动发现只更新IP，不更新其编译端口。

同一SSID不一定互通：访客Wi-Fi、AP隔离、手机热点和VPN可能拦截设备互访或UDP广播。先用手机确认HTTP能访问，再查UDP发现。发现失败时ESP会尝试本地配置的候选地址。

## 六、Linux运行

以Debian/Ubuntu为例，先进入完整项目根目录：

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r server/Robot_Server/requirements.txt
.venv/bin/python -m pip check
.venv/bin/python server/Robot_Server/start_server.py --init-config
```

编辑生成的`config.json`后：

```bash
.venv/bin/python server/Robot_Server/start_server.py
```

模型下载见[模型与工具说明](识别模型与工具环境搭建.md)。服务账号需要对配置、模型目录、录音、图片和运行状态文件有读写权限。不要用root安装后让另一个无权限账号运行，也不要直接修改系统Python环境。

上述是局域网联调方式；Linux进程运行不等于完成公网部署。公网还涉及进程管理、反向代理、访问控制和上传超时。当前ESP按HTTP通信，若对外只开放HTTPS，需要额外安排与当前网关兼容的入口；UDP发现不能跨互联网。不要直接套用未验证的多进程WSGI命令：本服务的任务队列、锁和后台线程包含进程内状态。

## 七、启动和依赖检查

Windows：

```powershell
.\.venv\Scripts\python.exe -c "import flask, requests, PIL, cv2, numpy, faster_whisper, av; print('IMPORT_OK', cv2.__version__, av.__version__)"
.\.venv\Scripts\python.exe server/Robot_Server/asr_check.py --app-dir server/Robot_Server --dependencies
```

第二条会真实解码临时静音WAV，不下载权重。输出`ASR_DECODER_READY`表示解码链可用；识别权重是否就绪还需执行模型准备检查。Linux将解释器替换为`.venv/bin/python`。

## 八、常见问题

| 现象 | 优先检查 |
| --- | --- |
| 找不到`flask/cv2`等模块 | 是否用`.venv`的Python安装及运行；是否在正确项目根目录 |
| pip提示无匹配发行包 | 64位Python版本、系统架构、pip版本及所用索引是否有指定版本wheel；不要随意删除兼容版本约束 |
| `open() got an unexpected keyword argument 'metadata_errors'` | 本虚拟环境是否实际使用faster-whisper1.2.1 + av18.1.0，再运行解码检查 |
| 端口被占用/设备上线时灵时不灵 | 是否还有旧服务进程同时占用HTTP5000或UDP5001，不要连续启动多份服务 |
| 本机可开、ESP/手机打不开 | 监听host、防火墙、实际网卡IP、访客网络隔离、HTTP端口一致性 |
| 登录失败/设备报401 | 网页token与ESP token一致性，不是AI服务商Key；配置修改后是否重启相应端 |
| 语音已上传但未识别 | 模型是否就绪、音频能否试听、是否确有清晰人声及识别队列状态 |
| 改名后找不到配置 | 保持完整目录结构，使用`start_server.py`入口；私有配置是服务目录中的文件 |

`config.json`、`.session_key`、运行数据由忽略规则排除；不要把真实口令填写进公开模板。`.session_key`用于网页登录签名，不需要抄进ESP；也不要在服务运行时随意删除。
